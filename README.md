# 세명대학교 학식 알리미 (iOS)

세명대학교 학식 알리미는 세명대학교 학생들을 위한 학생식당 메뉴 정보 앱입니다.

매일 바뀌는 학식 메뉴를 한눈에 확인하고, 홈 화면 위젯으로 빠르게 접근할 수 있습니다.
